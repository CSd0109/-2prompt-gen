# Contributing to AI Prompt Generate 🤝

We love contributions from the generative AI, prompt engineering, and open-source community!

## How You Can Contribute

1. **Submit New Prompts:**
   - Share high-converting prompts for Midjourney, Flux 1.1, Sora, Kling, or ChatGPT.
   - Test them on our live platform at [AI Prompt Generate](https://aipromptgenerate.xyz).

2. **Add Categories & Features:**
   - Open a pull request or file an issue to suggest new prompt categories (e.g. 3D Icons, Architecture, UI Design).

3. **Link Exchange & AI Partnerships:**
   - If you run an AI tool, directory, or generative art blog, we welcome backlink partnerships.
   - Contact us via our partner portal at [https://aipromptgenerate.xyz](https://aipromptgenerate.xyz) or reach out via email.

---

### Contribution Steps

```bash
# 1. Fork the repository
# 2. Create your feature branch
git checkout -b feature/awesome-prompts

# 3. Commit your changes
git commit -m "feat: add photorealistic portrait prompts"

# 4. Push to branch
git push origin feature/awesome-prompts

# 5. Open a Pull Request
```

Thank you for helping empower creators worldwide! 🚀
